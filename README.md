# Activity 05 — CSS Arcade Night

## Overview
This project is part of Activity 05: CSS Arcade Night. It focuses on practicing CSS skills, identifying styling issues, correcting CSS, and documenting the results from each round.

The project includes the webpage, stylesheet, and folders for organizing screenshots, findings, and other submission evidence.

## Project Files

- `index.html` — Main webpage for the activity.
- `styles.css` — CSS styles used to design and format the webpage.
- `evidence-template.md` — Template for recording observations, findings, and evidence.
- `submission-links.txt` — File for organizing the links required for submission.
- `round1/` — Round 1 screenshots, score, and findings.
- `round2/` — CSS diagnoses, corrections, and before-and-after screenshots.
- `round3/` — Checkpoint screenshots and related evidence.
- `screenshots/` — Additional screenshots collected during the activity.

## Activity Details

### Round 1 — Score and Findings
Record your score and include the screenshot from Round 1. Write a short explanation of what you observed, what worked, and any difficulties you encountered.

### Round 2 — CSS Diagnosis and Correction
Identify the CSS issues, explain what caused them, and document the changes made to correct them. Include screenshots showing the page before and after the corrections.

### Round 3 — Checkpoints
Include screenshots of the required checkpoints and briefly describe your progress and the results you observed.

## Evidence and Submission

All screenshots and findings should be based on your actual work during the activity. Keep the evidence organized in the corresponding round folders and use the evidence template to document your observations.

Before submitting, check that:
- The webpage and stylesheet are included.
- Each required round has its own evidence.
- Screenshots clearly show the relevant results.
- Findings and CSS corrections are documented.
- All required submission links are provided.
